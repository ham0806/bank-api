# ADR 0001: 金額・仕訳・冪等性の設計

## 決定

- 金額は円単位の `long` とする。
- `accounts.balance_minor` は照会用の現在残高として保持する。
- `ledger_entries` を残高の根拠となる記録として保持する。
- 状態変更リクエストには `Idempotency-Key` を要求する。
- キーとリクエストハッシュをDBへ保存する。
- キーの一意制約を設ける。

## 理由

浮動小数点誤差を避け、残高更新だけでなく仕訳の監査可能性を確保するためです。ネットワークタイムアウト後の再送はアプリケーションの状態だけでなくDB制約でも防止します。
